### 🚀 Featured & Open-Source Projects

#### 1. [Wecncode/Social-Sentinel](https://github.com/Wecncode/Social-Sentinel) *(Core Contributor)*
* **Description:** An open-source, AI-powered NLP tool designed to detect psychological manipulation, artificial urgency, and zero-day social engineering tactics in emails and chat messages before a victim is coerced.
* **Key Focus:** Semantic intent analysis, rule-based psychological heuristics, and zero-day BEC (Business Email Compromise) mitigation.
* **Tech Stack:** `Python`, `NLP`, `Transformers`, `Pytest`, `Regex Semantics`

#### 2. [Tool-Using AI Agent Security Capstone](https://github.com/Kamogelo0911/ai-agent-security-capstone)
* **Description:** Developed a local customer support AI agent with SQL tool execution to evaluate resistance against OWASP GenAI risks (LLM01 Prompt Injection & LLM08 Excessive Agency).
* **Key Focus:** Demonstrated that server-side ownership checks, parameterised SQL, and input validation reliably block unauthorized operations even when LLM prompt instructions fail.
* **Tech Stack:** `Python`, `Ollama (llama3.2:3b)`, `SQLite`, `Pytest`

#### 3. [AI Prompt Injection & Spam Classifier](https://github.com/Kamogelo0911)
* **Description:** Transformer and Machine Learning pipelines built to intercept malicious user prompts (jailbreaks/instruction manipulation) and filter out email social engineering spam.
* **Tech Stack:** `Python`, `Scikit-Learn`, `PyTorch`, `DeBERTa`
